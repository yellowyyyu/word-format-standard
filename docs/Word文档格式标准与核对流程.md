# Word 文档格式标准与核对流程

> 把对 Word 文档的全部格式要求整理成一份标准（示例版，2026-10-10 定，2026-10-12 更新）。
> 以后凡是处理文档，先按这份标准来做，再按核对流程检查；全部通过才算完成。
> （同目录还有排版好的 `.docx` 版，本身就是"按标准排版"的活样板。）

## 一、四条基本原则

1. 改重要文档之前，先复制一份备份；备份名字里写明"改什么之前"和日期。过程备份在验收后只留"原始 + 最新"。
2. 只做要求的事，不改变原文的意思和风格。
3. 每份文档改完，必须自查一遍（自动检查 + 人工核对），发现问题当场修好、重新检查，再交付。
4. 处理过程中产生的中间文件（临时副本、试验稿、过程截图等）由处理者自行清理；重要文档的过程备份，验收满意后也自动清理，只留"原始 + 最新"。清理一律走回收站（可恢复），清完报告清单。

## 二、格式标准一览

| 项目 | 要求 |
|---|---|
| 中文文字 | 宋体 |
| 英文、数字 | Times New Roman |
| 文章题目 | 二号（22 磅）、加粗、居中 |
| 正文 | 五号（10.5 磅）、开头空两格、两端对齐 |
| 各级标题 | 五号（与正文一样大）、加粗、顶格不空格 |
| 图表内文字与题注 | 小五（9 磅）、居中、不缩进 |
| 图表下的注（注：/ Note 行） | 小五（9 磅）、不缩进、靠左 |
| 表格内容 | 小五（9 磅）、居中；每个单元格尽量一行 |
| 参考文献 | 小五（9 磅）、悬挂缩进 2 字符 |
| 全文行距 | 单倍行距 |
| 段落间距 | 段前、段后都是 0 行 |
| 编号 | 用"1."式编号，少用圆圈数字①②③ |
| 显示公式 | 公式居中；编号手动输入顶到右侧（编号不放进公式内部） |
| 文字中的公式符号 | 与所在段落文字同字号；上下与文字对齐，不偏上不偏下 |

没有现成模板时按默认格式来：只用黑字；正文不倾斜、不用 Word 标题样式、不加边框底纹；表格用最简网格。

## 三、公式的专门规定

1. 显示公式（单独占一行的公式）：公式居中；编号（如 (1)(2)…）手动输入、顶到页面右侧；编号不要放进公式里，也不要放进 MathType。
2. 文字中的公式符号（如 S_W、α₁）：大小必须和所在段落的文字一样大（五号区 = 10.5 磅，小五区 = 9 磅）；上下位置必须与文字对齐——不偏上、不偏下。
3. 合格标准：用程序逐个符号测量它与文字的位置差，偏差不超过 0.5 磅（约 0.2 毫米，肉眼看不出来）才算合格；符号比文字明显大、顶端冒头或底部下沉，都算不合格。
4. 批量把公式转成 MathType 时，走专门流程：先删旧公式、再插新公式，每 3 条保存一次（见
   [word-formula-to-mathtype](https://github.com/yellowyyyu/word-formula-to-mathtype)）。

## 四、修改稿怎么标记

手动上色标记，不用 Word 修订模式：保留的内容保持黑色；删除的内容改成红色并加删除线；新增的内容用蓝色。公式保持 MathType 本体，不转成图片；公式内部不加标记，只把公式编号标蓝。

## 五、核对流程（每一步都要过）

**第 0 步 备份**：改动前先把原文件复制一份，备份名字包含"改动说明 + 日期"。

**第 1 步 自动检查**：运行 `tools/word_format_check.py`（由工具操作，人不用一行行看），把字体、字号、行距、段前段后（段距）、缩进、标题、题注、注行、表格、公式对象尺寸逐项过一遍。输出"[全部通过]"才算过关；有任何一条问题都要修好、重新检查，直到全绿。

**第 2 步 公式符号专项测量**：凡改动涉及公式符号，把文档导出成 PDF，运行 `tools/word_symbol_align_check.py`，逐个比对符号与文字的上下位置。全部偏差不超过 0.5 磅、符号大小等于所在段落字号，才算过关。

**第 3 步 人工逐项核对**（分成四遍做，每遍只看几项，看完一遍再看下一遍——一次看太多容易漏）：

- 第一遍（字体字号）：□ 题目二号、加粗、居中；□ 正文五号；□ 标题五号、加粗、顶格；□ 图表内文字与题注小五。
- 第二遍（段落版式）：□ 正文每段开头空两格、两端对齐；□ 全文单倍行距、行距均匀；□ 图表下的注靠左、不缩进；□ 参考文献小五、悬挂缩进 2 字符。
- 第三遍（公式专项）：□ 公式居中、编号顶右、不重复、公式内部无多余编号；□ 行内公式符号与文字同字号、不偏上不偏下（配合导出 PDF 检查，偏差 ≤ 0.5 磅）。
- 第四遍（整体通读）：□ 从头翻到尾：没有多余空白页、没有串行、没有乱码；□ 页码连续；□ 图表都在页面居中；□ 低级错零容忍——没有多余或缺失的空格，中英文标点没有混用，缩进没有异常。

**第 4 步 交付与验收**：报告做了什么、结果如何、备份在哪里；验收满意后，中间文件和过程备份自行清理（只留"原始 + 最新"，走回收站并给清单）。

## 六、常用工具与文件位置

- 格式检查程序：`~/.claude/tools/word_format_check.py`（对任意 Word 文件都能运行）
- 公式符号测量程序：`~/.claude/tools/word_symbol_align_check.py`（把文档导出 PDF 后运行）
- 公式符号大小修复程序：`~/.claude/tools/word_inline_eq_resize.py`（需要时使用）
- 个人习惯档案（配套系统）：`~/.claude/user-profile/`

## 七、还没有特别规定的事项（可随时补充）

1. 页边距、页眉页脚、页码的位置和样式；
2. 摘要、关键词、致谢等部分的字体字号；
3. 参考文献的著录格式细节（目前只定了"小五 + 悬挂缩进 2 字符"）；
4. 表格线粗细、底纹颜色等外观。
